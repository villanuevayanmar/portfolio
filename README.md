# Yanmar Villanueva — Portfolio

A personal portfolio for showcasing projects, experiments, and practical digital tools.

## Overview

The site is built with the Next.js App Router, React, TypeScript, and Tailwind CSS. It includes an editorial-style introduction, an about section, a filterable project archive, a toolkit overview, and direct contact links.

## Features

- Responsive layout with a distinctive paper, ink, coral, and lime color palette
- Filterable project archive with links to live previews and source repositories
- Contact through email and GitHub
- No database or visitor-tracking service required

## Run locally

\`\`\`bash
npm install
npm run dev
\`\`\`

Open http://localhost:3000.

## Production build

\`\`\`bash
npm run build
npm start
\`\`\`

## Projects

Project details are maintained in data/content.ts, so the project list and profile information can be updated in one place.

## Deployment

The project can be deployed to any platform that supports Next.js. No Supabase credentials or database setup are needed for this portfolio.
